# AI知识库管理

用于查看或修改 AI 知识库基本资料。建站前整理本次需求仍走建站流程，不使用本流程保存。

以下说法均指向同一份 AI 知识库基本资料：`AI知识库基本资料`、`公司资料`、`公司基本资料`、`企业资料`、`企业基本资料`、`网站基本资料`。用户单独要求查看、检查、补充或修改这些资料时，必须先调用 `nicebox_get_knowledge_profile`，不能只使用对话中记忆的旧资料。

仅当用户已经明确处于新建或重新生成网站流程，并且正在提供“本次建站使用的资料或需求”时，才按建站流程整理需求；用户只是说“查看公司资料”“修改企业资料”等，不得误路由到建站资料整理工具。

## 基本资料

### 查看

调用 `nicebox_get_knowledge_profile`。只展示用户要求的字段；用户要求全部资料时展示公司名称、网站名称、Logo、域名、行业、电话、邮箱、地址、关联平台和公司简介。

### 修改

1. 先调用 `nicebox_get_knowledge_profile`，取得最新值和 `updated_at`。
2. 只把用户明确修改的字段放进 `changes`；未提到的字段不得提交，只有明确要求清空时才传空值。
3. 展示旧值与新值，并提示基本资料为账号级共享，可能影响同账号其他站点及后续 AI 生成。
4. 用户确认后调用 `nicebox_update_knowledge_profile`，传最新 `expected_updated_at` 和 `confirmed=true`。
5. 并发冲突时重新读取并重新确认，不能覆盖最新数据。

域名是访问和发布相关配置，只有用户明确要求修改域名时才能提交。Logo 若来自上传或 AI 候选，先调用 `nicebox_upload_images(purpose=logo)`，再保存返回的稳定 `image_url`。

## 连接切换

更换 API Key、重新连接或站点身份变化后，废弃旧资料和 `updated_at`；写入前重新读取。

## 回退

优先宿主 MCP 能力。仅连接层明确失败且写入未执行时，使用 `api_tool.py` 中同名普通 REST 回退。校验、权限、冲突或确认错误不得换通道绕过；写入结果未知时先重新查询目标。
