# 新增独立 FAQ 与 FAQ 分类

本流程只创建 FAQ 管理页面中的独立 FAQ 和 FAQ 分类，不写入文章或产品的 `faq_items`，也不修改页面模板。

## FAQ 分类

1. 用户查看 FAQ 分类时调用 FAQ 分类列表；用户给出编号时精确搜索，给出名称时模糊搜索。只查询 FAQ 分类，不混用文章或产品分类。
2. 创建分类前先按名称和语言搜索，避免重复。顶级分类使用 `parent_id=0`；子分类必须从查询结果选择真实父分类编号，且父子语言一致。
3. 收集分类名称、语言、父分类和可选排序，展示摘要。用户意图和参数明确时可直接创建；同级同语言重名时提示使用已有分类或更换名称。

## 新增独立 FAQ

1. 收集问题、答案、语言，以及可选的分类、发布时间、显示状态和排序。未指定时：无分类、当前时间、显示、自动追加排序。
2. 指定分类时先查看或搜索 FAQ 分类并使用真实编号。目标分类不存在时，优先使用宿主结构化选项：`创建该分类并继续`、`使用无分类`、`重新选择分类`；不得直接声称不支持创建 FAQ 分类。
3. 创建前展示本次 FAQ 摘要，并优先显示三个可点击单选项：`确认创建`、`调整内容`、`取消`。宿主不支持原生选项时才使用相同文本选项。
4. 选择确认后创建一条独立 FAQ。分类或其他参数变化后原确认失效，重新展示摘要。
5. 创建成功只报告 FAQ 编号、问题、分类和显示状态；不进入文章/产品预览、SEO、Schema 或整站发布流程。

FAQ 数量达到套餐上限时如实提示，不能改为创建文章/产品 FAQ，也不能通过页面 HTML 写死内容。
